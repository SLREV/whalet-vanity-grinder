Keamanan

  • Kunci dibuat lokal. APK tidak memiliki izin internet; versi web hanya mengambil aset aplikasi saat pertama dibuka. Pencarian tidak mengirim private key ke mana pun.
  • File hasil berisi private key. Siapa pun yang punya file itu bisa menguras isi wallet. Jangan diunggah, jangan dibagikan.
  • Hasil tidak disimpan otomatis. Riwayat hanya ada selama aplikasi terbuka, kecuali kamu menekan “Simpan”.
  • Keypair dibuat tanpa seed phrase, sama seperti solana-keygen grind. Untuk pemulihan lewat seed phrase pakai Solana CLI.

Tentang VanitySol

Cara pakai hasilnya

File <ALAMAT>.json berisi 64 angka (32 byte secret + 32 byte public), format yang sama persis dengan keluaran solana-keygen. 

solana config set --keypair ./vanity-keys/<ALAMAT>.json
solana balance

Kenapa lama?

Rata-rata percobaan = 58^panjang prefix, dibagi 2^jumlah huruf kalau “abaikan besar/kecil huruf” aktif. Tiap tambahan satu karakter membuat pencarian 58× lebih lama.

Tips

  • Pakai 3–4 huruf pertama namamu saja, bukan nama penuh.
  • Selalu aktifkan “abaikan besar/kecil huruf” (sampai 16× lebih cepat).
  • Colokkan charger: pencarian memakai CPU terus-menerus.

Privasi

Tidak ada iklan, analytics, atau pengiriman data. APK tidak meminta izin internet. Versi web mengambil aset statis untuk pembukaan awal; setelah terpasang, pencarian berjalan lokal di perangkat. File private key hanya dibuat jika kamu menekan “Simpan”.
