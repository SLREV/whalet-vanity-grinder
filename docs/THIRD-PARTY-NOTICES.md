# Pemberitahuan lisensi pihak ketiga

Build VanitySol menyalin teks lisensi penuh dari versi dependency di `package-lock.json` ke `www/licenses/` dan membundelkannya bersama asset web Android/PWA. Daftar tersebut mencakup Capacitor Core/Android, Filesystem, Share, Haptics, Status Bar, `@capacitor/synapse`, serta TweetNaCl. File `app/vendor/nacl-fast.LICENSE` juga disertakan.

Dependensi Android transitive (termasuk AndroidX) tetap mengikuti lisensi masing-masing; metadata/pemberitahuan open-source Android dapat ditinjau melalui Android Studio/Play Console. Sebelum penjualan, pemilik aplikasi perlu memastikan hak atas merek, ikon, dan kode milik sendiri. Repo ini tidak menetapkan lisensi komersial untuk kode VanitySol.
